## 🔑 КЛЮЧОВІ ЗНАХІДКИ

### 1. Stripe домінує для Mobile First SPA (2024-2025)
**Деталі:** Stripe Payment Element підтримує 100+ методів оплати з AI-powered динамічним показом. Express Checkout Element забезпечує one-click для Apple Pay, Google Pay, PayPal, Link. Transaction fees: 2.9% + $0.30.

**Важливість для Mobile First:** Pre-built компоненти автоматично адаптуються під мобільні екрани, дотримуються 44x44px touch targets, proper keyboard types.

**Практичне застосування:** Використовувати Stripe Elements з React/Vue wrapper, що зменшує PCI scope до SAQ A.

### 2. Токенізація - єдиний правильний підхід для frontend
**Деталі:** Network tokenization замінює Primary Account Number унікальним токеном. Card data НІКОЛИ не торкається JavaScript коду.

**Важливість:** PCI DSS compliance (SAQ A), знижує fraud на 40%, автоматично оновлює expired cards.

**Практичне застосування:** `stripe.createPaymentMethod()` для token generation, НІКОЛИ не зберігати card data в localStorage.

### 3. localStorage shopping cart оптимальний для Mobile SPA
**Деталі:** cart-localstorage (2.2KB, zero dependencies) або custom vanilla JS. Persist між сесіями, offline-ready.

**Важливість:** Instant response, працює на 3G, zero server requests для cart operations.

**Практичне застосування:** Pub/Sub pattern, debounce updates (300ms), ARIA live regions для accessibility.

### 4. Multi-step checkout переважає single-page на mobile
**Деталі:** 3-4 кроки, 2-3 поля per step. Baymard Institute: зменшує cognitive load у constrained viewport (50% - keyboard).

**Важливість:** Business card-sized viewport вимагає фокусу, легша error recovery.

**Практичне застосування:** Accordions між кроками, progress indicators, sessionStorage для state.

### 5. HTML5 autocomplete критичний для conversion
**Деталі:** Правильні attributes забезпечують 30% швидше заповнення. Safari, Chrome використовують різні strategies.

**Важливість:** Mobile typing складний, autocomplete зменшує friction в 2-3 рази.

**Практичне застосування:** `autocomplete="cc-number"`, `autocomplete="shipping street-address"`, `inputmode="numeric"`, `font-size: 16px`.

### 6. PCI DSS SAQ A - єдиний realistic шлях
**Деталі:** SAQ A для merchants які НЕ торкаються card data - 12-30 requirements vs 251 full compliance.

**Важливість:** Mobile-optimized payment UI без complex infrastructure, знижує liability.

**Практичне застосування:** Hosted payment forms (Stripe Elements), strict CSP, regular audits.

### 7. Content Security Policy обов'язковий
**Деталі:** PCI DSS v4.0 Requirements 6.4.3, 11.6.1. Nonce-based CSP найбезпечніший.

**Важливість:** Mobile browsers вразливі до XSS, card skimming.

**Практичне застосування:** `script-src 'self' 'nonce-{NONCE}' https://js.stripe.com`, SRI для external scripts.

### 8. Apple Pay/Google Pay must-have
**Деталі:** One-click checkout з biometric auth, zero typing. 92% mobile browsers підтримують.

**Важливість:** Mobile wallet usage +40% у 2024, підвищує conversion 20-30%.

**Практичне застосування:** Stripe Express Checkout Element, progressive enhancement.

### 9. Order confirmation критичний для trust
**Деталі:** Must-have: зелений checkmark, order number, email note, delivery estimate.

**Важливість:** Mobile users тривожні, потребують instant reassurance.

**Практичне застосування:** Serverless functions (Netlify/Vercel + SendGrid), post-purchase upsells (+20-40% AOV).

### 10. HTTPS та security headers non-negotiable
**Деталі:** TLS 1.2+ mandatory, HSTS header, force redirects, proper certificates.

**Важливість:** Mobile networks менш безпечні (public WiFi), MITM attacks.

**Практичне застосування:** Let's Encrypt auto-renewal, SSL Labs A+ rating, application-level redirects.

## ⭐ BEST PRACTICES

### 1. Використовуйте Stripe Elements для Mobile UX

**Що робити:** Інтегрувати Stripe Payment Element, Express Checkout Element, React/Vue wrappers.

**Чому працює:** Pre-built UI з mobile best practices, auto PCI compliance (SAQ A), 100+ payment methods.

**Mobile First специфіка:** Responsive out-of-the-box, touch-optimized, proper keyboards, loading states.

```jsx
import { loadStripe } from '@stripe/stripe-js';
import { Elements, PaymentElement, useStripe, useElements } from '@stripe/react-stripe-js';

const stripePromise = loadStripe('pk_live_xxx');

function CheckoutForm() {
  const stripe = useStripe();
  const elements = useElements();
  const [isLoading, setIsLoading] = useState(false);

  const handleSubmit = async (e) => {
    e.preventDefault();
    if (!stripe || !elements) return;
    
    setIsLoading(true);
    const { error } = await stripe.confirmPayment({
      elements,
      confirmParams: { return_url: 'https://yoursite.com/complete' },
    });
    if (error) console.error(error.message);
    setIsLoading(false);
  };

  return (
    <form onSubmit={handleSubmit}>
      <PaymentElement options={{ layout: { type: 'accordion' } }} />
      <button disabled={!stripe || isLoading} style={{ width: '100%', minHeight: '48px' }}>
        {isLoading ? 'Processing...' : 'Pay now'}
      </button>
    </form>
  );
}
```

### 2. Implement localStorage shopping cart

**Що робити:** cart-localstorage (2.2KB) або custom, Pub/Sub pattern, ARIA live regions.

```javascript
class ShoppingCart {
  constructor() {
    this.items = JSON.parse(localStorage.getItem('cart') || '[]');
    this.listeners = [];
  }
  
  addItem(product) {
    const existing = this.items.find(i => i.id === product.id);
    if (existing) existing.quantity++;
    else this.items.push({ ...product, quantity: 1 });
    this.save();
    this.notify();
    this.announce(`${product.name} added to cart`);
  }
  
  save() { localStorage.setItem('cart', JSON.stringify(this.items)); }
  subscribe(callback) { this.listeners.push(callback); }
  notify() { this.listeners.forEach(fn => fn(this.items)); }
  announce(msg) { document.getElementById('announcer').textContent = msg; }
}
```

## 💻 CODE SNIPPETS & TEMPLATES

### Template 1: Complete Stripe Integration (React)

**Коли використовувати:** Mobile First SPA landing з payment, PCI compliant  
**Mobile considerations:** Responsive UI, touch-optimized, proper keyboards

```jsx
import React, { useState } from 'react';
import { loadStripe } from '@stripe/stripe-js';
import { Elements, PaymentElement, useStripe, useElements } from '@stripe/react-stripe-js';

const stripePromise = loadStripe(process.env.REACT_APP_STRIPE_KEY);

function PaymentForm({ orderId, orderTotal }) {
  const stripe = useStripe();
  const elements = useElements();
  const [isProcessing, setIsProcessing] = useState(false);
  const [error, setError] = useState(null);

  const handleSubmit = async (e) => {
    e.preventDefault();
    if (!stripe || !elements) return;
    
    setIsProcessing(true);
    try {
      const intentRes = await fetch('/api/create-payment-intent', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ orderId })
      });
      const { clientSecret } = await intentRes.json();

      const { error, paymentIntent } = await stripe.confirmPayment({
        elements,
        confirmParams: { return_url: `${window.location.origin}/confirmation` },
        redirect: 'if_required'
      });

      if (error) setError(error.message);
      else if (paymentIntent?.status === 'succeeded') {
        await fetch('/api/verify-payment', {
          method: 'POST',
          body: JSON.stringify({ paymentIntentId: paymentIntent.id, orderId })
        });
        window.location.href = `/confirmation?orderId=${orderId}`;
      }
    } catch (err) {
      setError(err.message);
    } finally {
      setIsProcessing(false);
    }
  };

  return (
    <form onSubmit={handleSubmit} style={{ padding: '24px' }}>
      <PaymentElement options={{ layout: { type: 'accordion' } }} />
      {error && <div style={{ color: '#dc3545', marginTop: '16px' }}>{error}</div>}
      <button 
        type="submit" 
        disabled={!stripe || isProcessing}
        style={{ width: '100%', minHeight: '48px', marginTop: '24px', background: '#4834d4', color: 'white', border: 'none', borderRadius: '8px', fontSize: '18px' }}
      >
        {isProcessing ? 'Processing...' : `Pay $${orderTotal}`}
      </button>
    </form>
  );
}

export default function Checkout({ orderId, orderTotal }) {
  return (
    <Elements stripe={stripePromise} options={{ appearance: { theme: 'stripe', variables: { fontSizeBase: '16px' } } }}>
      <PaymentForm orderId={orderId} orderTotal={orderTotal} />
    </Elements>
  );
}
```

### Template 2: LocalStorage Cart (Vanilla JS)

**Коли використовувати:** Легкі SPA без backend  
**Mobile considerations:** Sticky bar, touch controls, ARIA

```javascript
class ShoppingCart {
  constructor() {
    this.items = JSON.parse(localStorage.getItem('cart') || '[]');
    this.render();
  }
  
  addItem(product) {
    const existing = this.items.find(i => i.id === product.id);
    if (existing) existing.quantity++;
    else this.items.push({ ...product, quantity: 1 });
    this.save();
    this.render();
    this.announce(`${product.name} added. Cart has ${this.items.length} items.`);
  }
  
  updateQuantity(id, qty) {
    const item = this.items.find(i => i.id === id);
    if (item) { item.quantity = Math.max(1, parseInt(qty)); this.save(); this.render(); }
  }
  
  removeItem(id) {
    this.items = this.items.filter(i => i.id !== id);
    this.save();
    this.render();
  }
  
  getTotal() { return this.items.reduce((sum, i) => sum + (i.price * i.quantity), 0); }
  save() { localStorage.setItem('cart', JSON.stringify(this.items)); }
  
  render() {
    document.getElementById('cart-count').textContent = this.items.length;
    document.getElementById('cart-total').textContent = `$${this.getTotal().toFixed(2)}`;
  }
  
  announce(msg) {
    const el = document.getElementById('announcer');
    el.textContent = msg;
    setTimeout(() => el.textContent = '', 1000);
  }
}

const cart = new ShoppingCart();
```

## ⚠️ ТИПОВІ ПОМИЛКИ ТА ЯК ЇХ УНИКНУТИ

### Помилка 1: Зберігання card data в localStorage

**Чому проблема:** PCI DSS violation, security vulnerability, legal liability.

**Рішення:** НІКОЛИ не зберігати card data. Використовувати tokenization.

```javascript
// ❌ WRONG
localStorage.setItem('cardNumber', '4242424242424242');

// ✅ CORRECT
const { token } = await stripe.createToken(cardElement);
// Send only token to server
```

### Помилка 2: Приймати amount від frontend

**Чому проблема:** Can be manipulated через DevTools, payment fraud.

**Рішення:** Calculate server-side, fetch order from DB.

```javascript
// ❌ WRONG
app.post('/charge', (req) => {
  const { amount } = req.body; // Vulnerable!
});

// ✅ CORRECT
app.post('/charge', async (req) => {
  const order = await db.orders.findById(req.body.orderId);
  const amount = calculateTotal(order); // Server-side
});
```

### Помилка 3: Missing CSP headers

**Чому проблема:** Vulnerable to XSS attacks, card skimming, PCI non-compliance.

**Рішення:** Implement strict nonce-based CSP.

```javascript
// ✅ CORRECT
const nonce = crypto.randomBytes(16).toString('base64');
res.setHeader('Content-Security-Policy', `script-src 'self' 'nonce-${nonce}' https://js.stripe.com`);
```

### Помилка 4: Font-size < 16px на input

**Чому проблема:** iOS Safari zooms на focus, поганий UX.

**Рішення:** Завжди font-size: 16px minimum.

```css
/* ✅ CORRECT */
input { font-size: 16px; }
```

### Помилка 5: Missing autocomplete attributes

**Чому проблема:** Slower form completion, lower conversion, поганий mobile UX.

**Рішення:** Додати правильні autocomplete values.

```html
<!-- ✅ CORRECT -->
<input type="email" autocomplete="email" inputmode="email">
<input type="tel" autocomplete="tel" inputmode="tel">
<input type="text" autocomplete="cc-number" inputmode="numeric">
```

### Помилка 6: Inline event handlers

**Чому проблема:** Violates CSP, security risk.

**Рішення:** Use addEventListener.

```html
<!-- ❌ WRONG -->
<button onclick="pay()">Pay</button>

<!-- ✅ CORRECT -->
<button id="payBtn">Pay</button>
<script nonce="{nonce}">
  document.getElementById('payBtn').addEventListener('click', pay);
</script>
```

### Помилка 7: No payment verification

**Чому проблема:** Trust frontend status, fraud vulnerability.

**Рішення:** Verify server-side via payment gateway API.

```javascript
// ✅ CORRECT
const paymentIntent = await stripe.paymentIntents.retrieve(id);
if (paymentIntent.status === 'succeeded') {
  await db.orders.update(orderId, { status: 'paid' });
}
```
